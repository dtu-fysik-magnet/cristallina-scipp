# cristallina-scipp

Tools for looking at SwissFEL/Cristallina data with [scipp](https://scipp.github.io) and
[plopp](https://scipp.github.io/plopp). The beamline stack (`sfdata`, `jungfrau_utils`, `cristallina`) still does the
I/O and geometry; this package takes over from the reduced data:

* `reduce_scan`: per-step summed Jungfrau images. It applies lower and upper cutoffs (energy windows) and sums the
  detector and I0 (scalar or JF-I0 image) over the **same** pulses. Optionally the result is in photon counts with
  Poisson errors.
* `scan_means`: per-step means of BS/PV channels, with standard error or spread.
* `roi_intensities`, `crop`, `to_photons`.
* `peaks.fit_peaks` (lmfit, error-weighted) and `peaks.moments` (centroid and FWHM per step), `peaks.integrate`
  (area above a straight-line background, variances propagated, no clipping).
* `Catalogue`: one TOML file per experiment with run groups, ROIs and detector calibration by run range.
* `run_series` / `Catalogue.series`: one point per run (integral, fit, moments) with energy, field, transmission
  and group labels as coordinates. Saves to one HDF5 file (`series.save_hdf5(path)`) with per-run ROI bounds
  and scan paths, the settings in their units, the package version and the catalogue's SHA-256.
* `corrections`: `correct_transmission` (attenuators between the I0 monitor and the sample) and
  `correct_absorption` (fluorescence yield as a proxy for μ(E)), each recorded in the series' settings.
* `angles.detector_angles` / `geometry_from_step`: 2θ and ν coordinates, using the March 2026 calibration.
* `rsm.pixel_hkl` / `rsm.histogram`: reciprocal-space maps binned instead of nearest-neighbour interpolated.
* `testing`: small synthetic scans in the SwissFEL layout. They imitate the March 2026 runs 45, 51 and 55.

## Notebooks

* `notebooks/rsm.ipynb`: the adapter on the bundled cristallina test run, and binned vs interpolated RSMs.

## Documentation

The zensical site in `docs/` combines tutorials, how-tos and explanations with an API reference built from the
docstrings. Every code block comes from a script in `docs/scripts/` that the tests run.

```sh
uv sync --extra notebook --extra test --extra docs
uv run pytest
uv run python tools/build_docs.py          # or: ... serve
```

Elsewhere, `pip install .` fetches `sfdata` and `jungfrau_utils` from their public git
repositories; `pip install ".[rsm]"` adds `cristallina` (a ~200 MB download), which only `rsm.pixel_hkl` needs. On the Ra cluster: `pip install --no-deps -e .` plus `pip install scipp plopp lmfit` into the pgroup
kernel, keeping its own copies of the PSI packages.

Notebooks are generated by `tools/make_*notebook.py`.
